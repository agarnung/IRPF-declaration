# demo/

Static, self-contained report generated with mock data + the heuristic classifier.
No server, credentials or network are required.

- `index.html` — the report (KPIs, category summary, movements, downloads).
- `tabla_paypal_irpf_2026.csv` — per-transaction detail.
- `paypal_resumen_por_categoria.csv` — aggregated totals.
- `paypal_resumen_natural.txt` — plain-language summary.

Open `index.html` directly, or serve it from GitHub Pages / raw.githack:

```text
https://raw.githack.com/agarnung/IRPF-declaration/paypal-ai-hackathon-2026/demo/index.html
```

This is sample data, not real PayPal history and not tax advice.
